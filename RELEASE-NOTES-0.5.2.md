# KPC Launcher 0.5.2

Fixes character export failing during Steam game startup with **“Only part of a ReadProcessMemory or WriteProcessMemory request was completed.”** The launcher now identifies the game without reading its unfinished module list.

If an earlier export attempt left KurtzPel open, close the game, update the launcher, and choose **Export character** again. Select your character and enter the square to capture it.

Export remains available without tester access. Existing character files remain compatible and are preserved. Community connections continue through the VPS relay.
