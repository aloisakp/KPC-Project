# KPC Launcher 0.5.1

Character export is now available to everyone who authorizes Steam. No tester code, archive downloads or merged installation are required.

Choose **Export character**, select your character in the normal Steam game and enter the square. The launcher saves the character-named file, closes that game and confirms the capture. Use **Open exports folder** to find your file.

Merge, community Play and character import still require tester access. Existing export files remain compatible. All community connections continue through the VPS relay.

This update does not include the experimental Map 2 lighting changes.
